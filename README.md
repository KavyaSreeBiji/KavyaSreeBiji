### 💡 Featured Projects

**[Elder English Companion](https://github.com/KavyaSreeBiji)**
Accessible English-learning web app for elderly users — bilingual UI, voice-driven lessons via Groq + Web Speech API, Firebase auth and progress tracking. Designed around large fonts, high contrast, and slow-paced speech feedback.
`React` `Node.js` `Express` `Firebase` `Groq API`

**[Supply Chain Guardian](https://github.com/KavyaSreeBiji)**
Full-stack logistics dashboard consolidating real-time inventory, shipment tracking, and predictive risk into one view, with a Gemini-powered AI assistant for troubleshooting.
`React 19` `Django` `Gemini API` `Framer Motion`

**[Agora](https://github.com/KavyaSreeBiji)**
A multi-agent LLM orchestration system with a policy-driven evaluation pipeline for benchmarking agent decision-making.
`Python` `Multi-Agent Framework`

**[Vault — Finance Dashboard](https://github.com/KavyaSreeBiji)**
Personal finance tracker with fuzzy search, multi-filter sortable transactions, and zero-dependency Canvas-based charts. RBAC for Admin/Viewer roles.
`React 19` `Zustand` `Canvas API`

**[House Price Prediction](https://github.com/KavyaSreeBiji)**
Regression model for housing price prediction, with feature engineering and hyperparameter tuning to improve accuracy.
`Python` `scikit-learn` `Jupyter`
